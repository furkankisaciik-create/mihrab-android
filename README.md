# MIHRAB

Android ve iOS için React Native + Expo ile geliştirilen namaz uygulaması.

## İlk hedef

Google Play üzerinde yayınlanabilen sade ve güvenilir bir Android sürümü hazırlamak.
Aynı kod tabanı iOS desteğini korur.

## Çalıştırma

Bu çalışma klasöründe taşınabilir Node.js bulunur:

```powershell
cd mobile
..\node-v24.16.0-win-x64\npm.cmd start
```

Telefona Expo Go yükleyip terminalde gösterilen QR kodu tarayarak uygulama açılabilir.
